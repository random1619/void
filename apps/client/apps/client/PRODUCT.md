# Product Context — Ivory Atelier E-commerce

## What it is
A luxury e-commerce platform for "Ivory Atelier" (formerly "VOID") — a fictional high-end fashion brand selling curated collections of modern tailored garments. The platform emphasizes editorial presentation, craftsmanship storytelling, and an elevated shopping experience.

## Mode
**Persuade** — The landing page is designed to convert visitors into customers through aspirational brand storytelling, editorial imagery, and clear calls-to-action. Design is the product.

## Audience
- Affluent consumers seeking premium, limited-edition fashion
- Design-conscious shoppers who value craft and exclusivity
- Users who expect a refined, friction-free digital experience

## Core flows
1. **Discovery** — Browse collections, view products, read about brand philosophy
2. **Shopping** — Add to cart, customize (watches), checkout with Stripe
3. **Account** — Auth, order history, saved items
4. **Content** — Lookbooks, testimonials, newsletter signup

## Technical stack
- React 19 + TypeScript
- Vite build system
- React Router for navigation
- Framer Motion + GSAP for animations
- Tailwind CSS for styling
- Three.js for 3D product visualization (watches)
- Stripe for payments
- Zustand for state management
- React Query for data fetching
